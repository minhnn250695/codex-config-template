
# Project Instructions

## Purpose
This repository is used to learn AI-assisted software development.

## Engineering Principles
- Prefer simple, maintainable solutions.
- Avoid unnecessary dependencies.
- Explain important architectural trade-offs.
- Make small, focused changes.

## Coding Standards
- Use Python 3.
- Prefer readable code over clever abstractions.
- Add tests for new behavior.
- Handle errors explicitly where appropriate.

## Workflow
1. Inspect relevant files before editing.
2. Explain the intended changes.
3. Implement the smallest useful solution.
4. Run relevant tests.
5. Summarize changes and any remaining risks.

## Safety
- Do not delete unrelated files.
- Do not introduce dependencies without explaining why.
- Ask before performing destructive operations.
- Never expose secrets or credentials.
